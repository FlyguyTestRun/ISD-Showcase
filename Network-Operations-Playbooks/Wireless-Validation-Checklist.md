# Wireless Validation Checklist for K-12

## Coverage & Performance
- [ ] Campus walkthrough completed (instructional spaces, auditorium, testing areas)
- [ ] Minimum RSSI target met in learning areas
- [ ] Roaming behavior acceptable between AP zones
- [ ] Latency and packet-loss baseline within target

## Security & Policy
- [ ] Student SSID mapped to student VLAN and filtering policies
- [ ] Staff SSID mapped to staff VLAN with proper access controls
- [ ] Guest SSID isolated from internal resources
- [ ] 802.1X auth success/failure rates reviewed

## Instructional Readiness
- [ ] LMS load testing successful from student and staff networks
- [ ] Testing platform connectivity validated
- [ ] Classroom collaboration tools validated (Teams/web conferencing)

## Operations Readiness
- [ ] Alerts configured for AP down/high client load
- [ ] Runbook updated with known RF constraints
- [ ] Help desk guidance updated for common wireless tickets
