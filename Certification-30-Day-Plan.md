# 30-Day Certification Plan (Parallel to Job Search)

This plan is designed to strengthen interview positioning while continuing portfolio delivery.

## Priority Order
1. **CCNA (Networking credibility)**
2. **AZ-800/801 completion track (Hybrid systems depth)**
3. **SC-300 fundamentals (Identity/security governance)**

## Week-by-Week Plan

### Week 1
- Build baseline: exam objectives checklist and self-assessment
- Complete routing/switching fundamentals review (CCNA)
- Complete AZ-800 identity/governance modules

### Week 2
- CCNA: OSPF, VLAN, STP, DHCP, NAT labs
- AZ-801: hybrid services and migration scenarios
- 1 timed practice set for each track

### Week 3
- CCNA: wireless, security fundamentals, troubleshooting labs
- SC-300: Conditional Access, MFA, role assignment, identity protection concepts
- Gap-focused review based on practice test misses

### Week 4
- Final review and exam scheduling
- Update resume to: “Exam scheduled” for active track
- Prepare concise interview talking points tied to real-world implementation

## Daily Time Box (Practical)
- **60-90 min weekdays**
- **2-3 hours weekends**
- Focus on one domain per session to reduce context switching
